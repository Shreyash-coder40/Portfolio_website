## 🚀 Key Highlights & Features

- **🌐 Live Production Deployment**: Hosted on Vercel at [shreyash-portfolio-black.vercel.app](https://shreyash-portfolio-black.vercel.app).
- **✨ Interactive Neon Cursor & Particles**:
  - Custom canvas-based luminous neon orb trail dynamically harmonized with the active theme.
  - Micro-star and dot sprinkles triggered dynamically on scroll and mouse wheel interactions.
- **🎨 Dynamic Theme Switching**: Cyber Cyan, Royal Violet, Emerald Matrix, and Sunset Amber palettes with instant CSS variables transitions.
- **📊 Real-time Stats & Dynamic Badges**:
  - Live GitHub contribution calendar & summary cards.
  - LeetCode coding analytics (problems solved, acceptance rates, difficulty breakdowns).
  - Smooth intersection-observer counter animations.
- **🏆 Hackathon & Certification Showcases**:
  - **Smart India Hackathon (SIH 2026)**: Campus Round — **Rank Under 100** milestone badge.
  - Certifications from national hackathons and developer summits (ApexVisa, EcoCommand, NextShop, Buildathon, etc.).

## 💻 Local Setup & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Shreyash-coder40/Portfolio_website.git
   cd Portfolio_website
   ```

2. **Run locally using any static web server**:
   - Using Node.js `serve`:
     ```bash
     npx serve .
     ```
   - Using Python 3:
     ```bash
     python -m http.server 3000
     ```
   - Or open `index.html` directly in your favorite modern browser.

3. **Visit in browser**:
   Navigate to `http://localhost:3000` (or `http://localhost:5000`).
